Charge users for claiming listings.

== Description ==

HivePress Claim Listings is an extension for [HivePress](https://wordpress.org/plugins/hivepress/) plugin. It allows you to charge users for claiming listings.

[Demo](https://listinghive.hivepress.io/) | [Docs](https://help.hivepress.io/) | [Support](https://community.hivepress.io/)

== Frequently Asked Questions ==
= Where do I report security bugs found in this plugin? =
Please report security bugs found in the source code of the plugin through the [Patchstack Vulnerability Disclosure Program](https://patchstack.com/database/vdp/6d3c1d48-59f2-43ad-a467-5b1d48be5355). The Patchstack team will assist you with verification, CVE assignment, and notify the developers of this plugin.
